# AAR — цифрова платформа аналізу та накопичення досвіду

**After Action Review** для оборонних та виробничих підрозділів. Перетворює
кожну виконану операцію та кожне застосування виробу на структуроване знання,
яке повторно використовується при плануванні наступних дій.

## Філософія

Цикл безперервного навчання: **Виконання → Аналіз → Висновки → Застосування**.
Кожна подія — джерело знань. Без цього циклу немає розвитку.

## Ключові принципи

- **Дворівнева модель**: пономерні події + якісні AAR-кейси поверх них.
- **Offline-first**: повний функціонал без мережі, авто-синхронізація.
- **Гнучкість**: довідники, форми та класифікатори адмініструються без коду.
- **Максимум автоматизації**: авто-довідки, авто-тригери AAR, LLM-класифікація причин.
- **Нормативна сумісність**: формати, сумісні з наказом Міноборони № 440.

## Технологічний стек (MVP)

- Бекенд: Python 3.12 + FastAPI + PostgreSQL + Redis
- Фронтенд: React + Vite + PWA (Workbox, IndexedDB)
- LLM-шар: Claude API (Sonnet 4.6 / Haiku 4.5) з prompt caching
- Розгортання: on-prem, Docker Compose
