# Нормативна база

Перелік актів і методологічних документів, з якими має бути сумісна
платформа AAR. Кожен документ супроводжується витягом ключових форм,
реквізитів та термінів, що використовуються у системі.

## Інформаційна безпека

Захист контуру будується за серією **ISO/IEC 27000** (актуальна практика
2025–2026), а не за застарілою моделлю КСЗІ:

- **ISO/IEC 27001:2022** — Information security management systems (ISMS).
- **ISO/IEC 27002:2022** — контрольні заходи (controls).
- **ISO/IEC 27005** — управління ризиками інформаційної безпеки.
- **ISO/IEC 27017 / 27018** — за потреби (хмарні сервіси, PII).
- Закон України «Про захист інформації в інформаційно-комунікаційних системах»
  — рамковий, без прив'язки до конкретної моделі захисту.
