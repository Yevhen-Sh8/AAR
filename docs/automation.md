# Автоматизація

Платформа спроєктована за принципом «максимум автоматизації». Нижче — повний
перелік сценаріїв, кожен має ідентифікатор A1–A12 і прив'язку до етапу
дорожньої карти.

## Перелік

| # | Сценарій | Реалізація | Етап |
|---|---|---|---|
| **A1** | Прийом пономерних подій із виробництва | REST `POST /events`, ідемпотентний за `serial_no`; альтернатива — CSV/Excel імпорт у MVP | 3 |
| **A2** | Валідація та дедуплікація | JSON-schema, перевірка довідників, конфлікт-резолюшн «last writer wins + audit» | 3 |
| **A3** | Розрахунок Кеф, Кеф_обсл, Кв_обсл | SQL materialized view, перерахунок при кожній події | 3–4 |
| **A4** | Щоденна довідка | Cron 23:59 → PDF + XLSX → e-mail / Signal / Telegram | 3 |
| **A5** | Місячна звітність | Cron 1-го числа → повний пакет Т.4–Т.7 + рейтинг | 4 |
| **A6** | Тригери AAR-кейсів | Engine правил T1–T5, спрацювання → авто-створення кейсу | 5 |
| **A7** | Нагадування експлуатантам | Якщо немає даних за добу — push (PWA) + messenger | 5 |
| **A8** | LLM-класифікація вільнотекстових причин у коди а–д / а–р | Claude API (Sonnet 4.6 default, Haiku 4.5 для масових), prompt caching на класифікаторі | 6 |
| **A9** | LLM-генерація драфту підсумкового аналізу менеджера | Контекст із подій + індивідуальних звітів → проект висновків і рекомендацій | 6 |
| **A10** | Пошук аналогій у базі знань | Векторні embeddings по AAR-кейсах; підказки при плануванні | 6 |
| **A11** | Експорт у формати наказу № 440 | Шаблони Word/Excel: відомості, журнали, акти | 8 |
| **A12** | Незмінний аудит-лог | Append-only журнал подій + hash-chain цілісності | 10 |

## Принципи реалізації

1. **Ідемпотентність** усіх API-операцій з даними.
2. **Час події ≠ час прийому**: подія несе свій timestamp; ретроспективне
   надходження перераховує лише уражені періоди.
3. **Прозорість LLM-рішень**: будь-яка авто-класифікація A8 ставить confidence
   та зберігає первинний текст; оператор може перевизначити.
4. **Налаштовуваність порогів**: T1–T5 та поріг A7 змінюються адміном без коду.
5. **Безкоштовний контур**: жодна авто-функція не залежить від платних
   зовнішніх сервісів за замовч., крім LLM (Claude API) — який можна вимкнути,
   зберігши ручні режими.
