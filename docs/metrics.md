# Метрики ефективності — наукова нотація

Цей документ — єдине джерело істини для назв коефіцієнтів і формул, що
використовуються у платформі. Усі звіти, експорти, API-поля та змінні коду
дотримуються цієї нотації.

## Загальні позначення

| Символ | Розшифровка | Тип |
|---|---|---|
| `N_sorties` | Кількість пусків (запущених виробів) за період | int |
| `N_success` | Кількість виробів, які виконали польотне завдання | int |
| `N_lost` | Безповоротно втрачені | int |
| `N_repair` | Повернуті в ремонт | int |
| `N_loss_external` | Втрати, віднесені до **зовнішньої зони** (РЕБ, бойові фактори) | int |
| `N_loss_manufacturer` | Втрати, віднесені до **виробничої зони** (відмови вузлів) | int |
| `N_crew_loss` | Втрати + повернення у ремонт, віднесені до **зони обслуги** | int |

## Ключові показники

| Код у системі | Грецька | Назва | Формула |
|---|---|---|---|
| `MSR` | **η** | Mission Success Rate | `N_success / N_sorties` |
| `MSR_c` | **η_c** | Crew-adjusted MSR | `N_success / (N_sorties − N_loss_external − N_loss_manufacturer)` |
| `CLR` | **λ_c** | Crew Loss Rate | `N_crew_loss / N_sorties` |
| `ΔMSR` | **Δη** | Зміна MSR vs попередній період, у в.п. | `(MSR_curr − MSR_prev) × 100` |

> **Зауваження.** `MSR_c` — це «очищений» показник: знаменник виключає ті
> пуски, де втрата сталася через фактори поза контролем обслуги (зовнішні
> впливи, конструктивно-виробничі відмови). Саме він використовується для
> рейтингу експлуатантів і тригера T1.

## Рейтинг експлуатантів

Класифікація за `MSR_c` (η_c):

| Категорія | Поріг |
|---|---|
| **high** (висока готовність) | η_c ≥ 0.85 |
| **ok** (задовільна) | 0.70 ≤ η_c < 0.85 |
| **needs_training** (потребує до-підготовки) | η_c < 0.70 |

## Назви тригерів

| Тригер | TriggerType (DB) | Умова |
|---|---|---|
| T1 | `msr_drop` | η_c < 0.70 три доби поспіль |
| T2 | `repeated_reason` | Та сама причина ≥ 3 разів за 7 діб |
| T3 | `item_anomaly` | Серійний № отримав ≥ 2 ремонти/втрати за 30 діб |
| T4 | `enterprise_drop` | η підприємства впав > 10 в.п. day-over-day |
| T5 | `manual` | Створено вручну |

## Маппінг старих назв (для довідки)

Платформа раніше використовувала українські короткі назви; з версії
`v0.6.0-metrics` всі вони замінені:

| Стара назва | Нова |
|---|---|
| Кеф | MSR (η) |
| Кеф_обсл | MSR_c (η_c) |
| Кв_обсл | CLR (λ_c) |
| Δ Кеф | ΔMSR (Δη) |
| keff_drop (trigger) | msr_drop |

## Дотримання у коді

| Місце | Як використовувати |
|---|---|
| Pydantic-схеми | поля `msr`, `msr_c`, `clr`, `delta_msr_pp`, `msr_prev`, `msr_this` |
| SQLAlchemy моделі | `TriggerType.MSR_DROP` тощо |
| XLSX/PDF-заголовки | `"η (MSR)"`, `"η_c (MSR_c)"`, `"λ_c (CLR)"`, `"Δη (в.п.)"` |
| Документація | використовувати грецькі літери у формулах, латиницю — у назвах полів |
