# ПАСПОРТ ПРОГРАМНОГО ЗАБЕЗПЕЧЕННЯ

**Найменування:** Програмний комплекс «AAR» (After Action Review) — цифрова
платформа пономерного обліку ефективності виробів та накопичення досвіду.

**Позначення:** AAR-ПЗ

**Версія:** 1.7.0 (редакція «Хвилі 1–7»)

**Дата оформлення паспорта:** складається автоматично при передачі; актуальний
стан — за станом останнього коміту гілки `claude/equipment-tracking-system-3lB6U`.

## 2. Призначення

Програма призначена для:

1. **Пономерного обліку** використання виробів (два і більше типів) до 10+
   експлуатантами: кожна подія фіксується з результатом (успіх / втрата /
   повернення в ремонт) і причиною за класифікатором.
2. **Автоматичного формування** щоденної аналітичної довідки та місячної
   звітності з рейтингом експлуатантів.
3. **Систематичного накопичення досвіду** за методологією NATO Lessons Learned
   Handbook (4-те вид.): відкриття AAR-кейсів, проведення їх повним циклом,
   автоматична валідація рекомендацій за фактичними даними.
4. **Проактивної підготовки** до виконання завдань: реєстрація попереджень і
   ризиків до вильоту, автоматичний брифінг підготовки місії з ШІ-синтезом.

## 5. Технічні характеристики

**Серверна частина:**
- Python 3.12; FastAPI; SQLAlchemy 2 (async); Alembic; Anthropic SDK (LLM).
- Автентифікація: JWT (HS256); глобальний auth-gate у продуктивному режимі;
  rate-limit входу (20 спроб / 5 хв на IP).
- Безпека: HTTP security headers (CSP, HSTS, X-Frame-Options), TLS на рівні хостингу.

**Клієнтська частина:**
- React 18 + TypeScript + Vite; PWA (Workbox + IndexedDB); offline-first із
  чергою синхронізації подій.

**База даних:** PostgreSQL 16 (продуктив), SQLite in-memory (тестування).

## 8. Нормативна та методологічна основа

- NATO Lessons Learned Handbook, 4-те видання (JALLC, 2022);
- US Army TC 25-20 «A Leader's Guide to After-Action Reviews»;
- ISO/IEC 27001:2022 (контур інформаційної безпеки; замість КСЗІ за рішенням замовника);
- Наказ Міноборони України № 440 (форми обліку військового майна);
- Метрики: MSR (η), MSR_c (η_c), CLR (λ_c) — наукова латинська нотація.

## 9. Відомості про експлуатацію

- **Розгортання:** одноклікове через Render Blueprint (`render.yaml`) або
  Docker Compose. Детально — `docs/DEPLOY.md`.
- **Автентифікація:** початковий адміністратор створюється при першому старті
  (`AAR_ADMIN_EMAIL` / `AAR_ADMIN_PASSWORD`).
- **Резервне копіювання:** експорт JSON-знімка через розділ «Резервна копія»
  (роль admin) або платний план БД із PITR.
- **AI-функції:** вимкнені за замовчуванням; вмикаються ключем
  `AAR_ANTHROPIC_API_KEY` + `AAR_LLM_ENABLED=true`.

## 10. Гарантії та обмеження

- Класифікатори причин на старті — абстрактні (a–д / а–р) з можливістю заміни
  на реальні через довідники в адмінці.
- Інтеграція з системою «Оберіг» **не передбачена** (таємна система — рішення
  замовника, ADR-003).
- Демонстраційна версія (GitHub Pages) працює лише на читання, на синтетичних
  даних, без запису.
