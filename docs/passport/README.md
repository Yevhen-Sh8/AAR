# Комплект експлуатаційної документації AAR

репозиторію та оновлюються з кожною зміною, що впливає на склад або
поведінку системи.

**Джерело істини** щодо поточного технічного стану — `docs/PLATFORM.md`
(живий документ). Ці три документи — формалізований зріз для передачі
замовнику / на постачання. Версія комплекту синхронізована з версією ПЗ
(наразі **1.7.0**).

Готові `.docx`-версії генеруються з цих markdown-джерел на вимогу.
